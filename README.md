# burnout

A small worksheet for working out what is feeding burnout at work, based on Christina Maslach and Michael Leiter's six areas of worklife (workload, control, reward, community, fairness, values).

1. **What burnout is**: a short introduction to burnout and the six areas.
2. **Map it out**: place each thing that is bothering you in the area it belongs to, closer to the centre the more it bothers you, then check the thought behind it and decide whether it is worth acting on or letting be.
3. **Your plan**: everything you added, grouped by how much it bothers you and by area, with what you decided.

Everything is saved in the browser's local storage only; nothing is sent anywhere.

## Running it

It is plain HTML, CSS and JavaScript with no build step. Open `index.html` through any static file server, for example:

```sh
python3 -m http.server
```

Source for the six areas: Maslach, C. (2017). Finding solutions to the problem of burnout. *Consulting Psychology Journal: Practice and Research*, 69(2), 143–152.
